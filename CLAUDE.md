# PicoClaw Development Guide

## Build & Test
- `make build` - Build the project
- `make test` - Run tests
- `make deps` - Install dependencies

## Project Structure
- `cmd/picoclaw/` - CLI entry point
- `pkg/` - Core logic packages
- `workspace/` - Default agent workspace
